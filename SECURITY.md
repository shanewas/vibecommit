# Security Policy

## Supported Versions

VibeCommit is currently in active development. We recommend using the latest version from `main` or the most recent release tag.

| Version | Supported          |
| ------- | ------------------ |
| 0.5.x   | :white_check_mark: |
| < 0.5   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in VibeCommit, please report it responsibly:

- **Email**: shanewasahmed@gmail.com
- **GitHub**: Open a private security advisory at https://github.com/shanewas/vibecommit/security/advisories/new (preferred for coordinated disclosure)

Please include as much detail as possible:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will acknowledge receipt within 48 hours and aim to release a fix or mitigation plan within 7 days for critical issues.

We appreciate your help in keeping VibeCommit and its users safe. Responsible disclosure will be credited (unless you prefer to remain anonymous).

## Scope

This policy covers the VibeCommit CLI tool itself. Issues in dependencies should be reported to their respective maintainers (we will help coordinate if needed).

Thank you for your responsible disclosure! 🪄
